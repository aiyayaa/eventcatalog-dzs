## 建模规则

- 每条去重后的接口关系生成一个 command，便于 NodeGraph 呈现产生方、使用方与传输资源。
- `MQ`、`ELK`、`页面集成`、`文件共享/数据流` 生成 channel。
- `文件共享`、`共享存储`、`数据库` 生成 container。
- services 的 `sends` / `receives` 引用 command，并尽量通过 `to` / `from` 关联 channel/container。
